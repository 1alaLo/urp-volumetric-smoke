# 体积烟雾弹 · Unity URP

CS2 风格的**真体积**烟雾：解析式球体 ray-march、3D 噪声密度场、主光散射与自阴影，
并且烟会参与场景——被墙挡住、被子弹打穿、被爆炸撕散。附带一个可直接游玩的第一人称演示场景。

![preview](docs/preview.png)

## 特性

| | |
| --- | --- |
| **真体积** | 逐像素沿视线积分密度，不是 billboard 或序列帧。走进烟里、贴墙、被几何体切割都正确。 |
| **贴场景扩散** | 爆开瞬间烘焙场景体素场，烟被墙挡住、贴墙铺开，只从门洞灌进房间。 |
| **能被打穿** | 子弹留下撕裂状隧道，洞壁被噪声啃碎，约 1 秒后自行愈合。 |
| **能被炸散** | 破片手雷永久撕掉大部分密度并让烟团塌缩，而不是把烟吹得更大。 |
| **两种投掷物** | 破片手雷留下弹坑与浓烟损伤；闪光弹是白屏闪光，只轻轻推烟。 |

## 环境

| 依赖 | 版本 |
| --- | --- |
| Unity | 6000.5.6f1（Unity 6.1+） |
| URP | 17.5.0 |
| Input System | 1.20.0 |

URP Asset（`Assets/Settings/PC_RPAsset.asset`）中的 **Depth Texture** 必须开启。

## 快速开始

1. 用 Unity Hub 打开本工程
2. 打开 `Assets/SmokeVolumetric/Scenes/SmokeDemo.unity`
3. 点 **Play**（进入后鼠标会锁定，`Esc` 释放）

## 操作

| 输入 | 作用 |
| --- | --- |
| `WASD` / `Shift` / `Space` | 移动 / 冲刺 / 跳跃 |
| 左键 | 开枪（在烟里打出隧道） |
| 右键 | 烟雾弹（飞向准星，空中起烟） |
| `F` | 破片手雷（炸散烟团） |
| `G` | 闪光弹（白屏闪光） |
| `C` / `R` | 清除烟雾 / 回到出生点 |

## 场景

40 × 40 m 的场地：天桥与楼梯、有顶小巷、开放掩体、装卸平台、5 × 5 × 3.2 m 的单门烟室。
